Next.js E-commerce

Aplicação de e-commerce desenvolvida com Next.js e TypeScript, consumindo produtos da Fake Store API e utilizando geração estática para páginas de produtos.

🔗 Projeto online: https://mini-plataforma-nextjs.vercel.app/

Funcionalidades
Listagem de produtos através de API externa
Página individual para cada produto
Rotas dinâmicas
Geração estática com getStaticProps e getStaticPaths
Layout responsivo
Tratamento de erros
Notificações com Toast
Testes End-to-End com Playwright
Tecnologias
Next.js
TypeScript
Tailwind CSS
Material UI
Playwright
Fake Store API
Vercel
Testes

O projeto possui testes End-to-End utilizando Playwright para validar os principais fluxos da aplicação.

Para executar:

npx playwright test

Como executar

git clone https://github.com/JefersonPinho/nextjs-ecommerce.git

cd nextjs-ecommerce

npm install

npm run dev

Depois acesse:

http://localhost:3000
